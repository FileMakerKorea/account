# ACCOUNT 디자인 표준

등록일: 2026-09-30. 적용 범위: ACCOUNT 프로젝트의 화면 기획과 향후 구현.
사용자가 지정한 shadcn 기반 구성과 색상 토큰을 이 프로젝트의 디자인 기준으로 등록한다. 현재는 기획 단계이며 앱 초기화와 패키지 설치는 수행하지 않았다.

## 기준 출처와 우선순위

1. 사용자의 후속 디자인 지시를 우선한다.
2. 색상과 반경의 정본은 [tokens.css](./tokens.css)다. 사용자 제공값을 그대로 보존하고 HTML 엔티티와 이스케이프만 정상 CSS로 정리했다.
3. 구성 기준은 사용자 지정 `preset b0`, `base aria`, `template vite`다.
4. [사용자 지정 생성 페이지](https://ui.shadcn.com/create?base=aria&template=vite)와 [공식 테마 문서](https://ui.shadcn.com/docs/theming)를 참조한다.

공식 테마 문서에서는 의미 기반 CSS 변수, 배경과 전경의 짝, `.dark` 재정의 방식을 확인했다. 생성 페이지는 동적 설정 내용을 텍스트로 확인할 수 없었다. b0의 상세 구성은 검증한 것으로 간주하지 않는다. 후속 확인(2026-09-30)에서 [공식 React Aria 안내](https://ui.shadcn.com/docs/changelog/2026-07-react-aria)를 통해 `--base aria` 지원을 확인했다. 실제 프리셋 초기화와 패키지 호환성 검증은 아직 수행하지 않았다. URL에는 b0 값이 없으므로 이전 사용자 메시지의 프리셋 지정을 함께 보존한다.

## 사용자 지정 구성

다음 명령은 구현 시 참고할 사용자 제공 명령이며 실행 기록이 아니다. 실행 전에 당시 CLI의 옵션과 생성 결과를 확인한다. 생성 결과가 지정값과 다르면 자동으로 다른 기반으로 대체하지 않는다.

```sh
npx shadcn@latest init --preset b0 --base aria --template vite
npx shadcn@latest apply --preset b0
```

init은 초기 구성, apply는 기존 구성에 프리셋을 반영할 때의 참고 명령이다. 두 명령을 무조건 연속 실행하는 절차로 취급하지 않는다. 실제 도입 시 패키지 버전과 잠금 파일을 기록한다.

## 시각 기준

- 흰색·검정·회색 중심의 화면을 사용하고 색상은 정본 토큰을 참조한다.
- 기본 반경은 `0.625rem`이며 컴포넌트별 반경은 공통 반경 체계로 관리한다.
- 라이트와 다크 테마를 모두 설계한다. 다크의 `sidebar-primary` 파란색은 사용자 지정값이므로 유지한다.
- 배경·전경 토큰을 짝지어 적용한다. 임의의 색상값으로 개별 화면을 꾸미지 않는다.
- 차트는 chart-1부터 chart-5를 사용한다. 같은 색으로 오인하지 않도록 라벨과 선 모양 등을 함께 사용한다.
- 파괴적 작업과 오류에는 destructive를 사용한다. 수입·지출이라는 이유만으로 임의의 녹색·빨간색을 추가하지 않는다.

## ACCOUNT 화면 적용안

아래는 프로젝트 기획 제안이며 shadcn 사이트의 강제 규칙이 아니다. 화면 설계 시 구체화한다.

| 영역 | 기준 |
| --- | --- |
| 전체 구조 | 데스크톱은 왼쪽 메뉴와 본문, 좁은 화면은 접을 수 있는 메뉴 |
| 월별 현황 | 상단 월 선택과 지출 추가, 수입·지출·잔액 요약, 거래 내역 순서 |
| 거래 내역 | 검색·필터와 표 중심, 금액 오른쪽 정렬, 숫자 고정 자릿수 폭 |
| 지출 입력 | 공통 입력 폼, 필수값 표시, 저장·취소 및 검증 오류 표시 |
| 상세 화면 | 동일한 제목·설명·작업 버튼 배치와 간격 재사용 |
| 상태 | 로딩·빈 목록·검색 결과 없음·오류·저장 중 상태 구분 |

서체·아이콘 패키지·정확한 간격·화면별 반응형 전환점은 아직 지정되지 않았다. b0의 실제 생성 결과를 확인하고 한글 가독성을 검토한 뒤 확정한다.

## 구현과 검토 기준

공식 문서의 방식에 맞춰 `components.json`의 `tailwind.cssVariables`를 사용한다. 실제 앱의 전역 스타일과 Tailwind 토큰 연결은 구현 단계에서 구성한다. 현재 tokens.css는 기준 자산이며 앱에 연결된 스타일시트가 아니다.

화면 검토에서는 라이트·다크의 텍스트와 차트 대비, 키보드 탐색과 포커스, 입력 라벨, 대화상자 닫기와 포커스 복귀, 모바일에서 긴 항목명과 금액 표시를 확인한다. 현재 렌더링·접근성 검증을 완료한 것으로 간주하지 않는다.

표준 변경 시 이 문서와 tokens.css를 함께 갱신한다. 외부 프리셋 변경이 프로젝트의 등록된 토큰을 자동으로 대체하지 않도록 한다.
